CBF Theory & Visualization

Control Barrier Function Mathematics:

Safety Set Definition:

$$\mathcal{C} = \{x \in \mathbb{R}^n : h(x) \geq 0\}$$

Barrier Function (Squared Distance):

$$h(x) = \|x - x_{obs}\|^2 - r_{safe}^2$$

CBF Constraint:

$$\dot{h}(x) = \nabla h(x) \cdot \dot{x} \geq -\alpha h(x)$$

Gradient:

$$\nabla h(x) = 2(x - x_{obs})$$

Using squared distance provides continuous gradients and better numerical stability. Where $\alpha > 0$ is the class-$\mathcal{K}$ function parameter controlling convergence rate, and $r_{safe}$ includes both obstacle radius and safety margin.

HOCBF Theory

High-Order Control Barrier Functions:

For double integrator dynamics $\ddot{x} = u$ with position constraint $h_0(x) \geq 0$, we recursively define barrier functions until control $u$ appears explicitly.

Original Constraint:

$$h_0(x) = x - x_{obs} \geq 0$$

First-Order Barrier:

$$h_1(x,\dot{x}) = \dot{h}_0 + \alpha_1 h_0 = \dot{x} + \alpha_1 (x - x_{obs})$$

HOCBF Constraint:

$$\dot{h}_1 + \alpha_2 h_1 \geq 0$$

Control Law:

$$\dot{h}_1 = \ddot{x} + \alpha_1 \dot{x} = u + \alpha_1 \dot{x}$$ $$u \geq -\alpha_1 \dot{x} - \alpha_2 h_1$$

The parameters $\alpha_1, \alpha_2 > 0$ ensure exponential convergence to the safe set while maintaining forward invariance for the double integrator system.
