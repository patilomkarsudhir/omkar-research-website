HOCBF Theory

High-Order Control Barrier Functions:

For a double integrator system (ẍ = u) with position constraint h₀(x) ≥ 0, we recursively define new barrier functions until the control u appears.

h₀(x) = x - x_obs
h₁(x,ẋ) = ḣ₀ + α₁·h₀ = ẋ + α₁·h₀
CBF constraint: ḣ₁ + α₂·h₁ ≥ 0
ḣ₁ = ẍ + α₁·ḣ₀ = u + α₁·ẋ
(u + α₁·ẋ) + α₂·h₁ ≥ 0
u ≥ -α₁·ẋ - α₂·h₁
