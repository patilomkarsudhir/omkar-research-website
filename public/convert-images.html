Universal Image Format Converter

🤖 The Story Behind This Tool: I had asked VS Code Copilot to convert a PNG file to SVG. I was hoping it would directly handle the conversion. To my shock, it created an entire app for converting image formats in a few seconds to assist me in this conversion! What a time to be alive! Sharing with the community for fun! 🚀
Instructions: Convert between any image formats with advanced compression options! Upload any image file and choose your desired output format. Supports PNG, JPG, WebP, AVIF, SVG, GIF, BMP, and more.

Features: • Smart compression with target file size control
• Manual quality adjustment with real-time preview
• Progressive JPEG and PNG optimization
• Automatic compression based on image complexity
• Format optimization and privacy-focused (all processing happens in your browser)
