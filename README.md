# Research Site

- [omkarsudhirpatil.com](https://omkarsudhirpatil.com)
- Next.js App Router + Tailwind
- Live Google Scholar sync (server route + client UI)
- Interactive Demos

## Run locally
```bash
npm install
npm run dev
```

## Deploy on Vercel
1) Push folder to a GitHub repo.
2) Create Vercel project from that repo.
3) Add env vars `SCHOLAR_USER= YOUR GOOGLE SCHOLAR ID` and optionally `NEXT_PUBLIC_SCHOLAR_USER= YOUR GOOGLE SCHOLAR ID`.
4) Deploy, then open `/publications`.
